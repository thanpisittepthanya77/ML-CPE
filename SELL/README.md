# 🌸 ระบบจำแนกสายพันธุ์ดอกไอริสด้วย SVM (Iris Species Classification)

ระบบนี้เป็นการใช้โมเดล Support Vector Machine (SVM) พื้นฐานในการจำแนกสายพันธุ์ดอกไอริส 3 ชนิด (Setosa, Versicolor, Virginica) โดยประเมินจากลักษณะความกว้างและความยาวของกลีบดอกครับ

##  โครงสร้างการทำงาน (Modular Design)
เพื่อให้โค้ดอ่านง่ายและเป็นระเบียบ ระบบจึงถูกแบ่งออกเป็น 3 ไฟล์หลัก:
1. `data_prep.py` : ทำหน้าที่รับข้อมูล, แบ่งชุดข้อมูล (Train/Test) และปรับสเกลข้อมูล (Feature Scaling)
2. `model_dev.py` : ทำหน้าที่สร้างโมเดล SVM, เทรนโมเดล และวัดผลความแม่นยำ
3. `main.py` : ไฟล์ควบคุมหลักสำหรับสั่งรันการทำงานตามลำดับ

##  ขั้นตอนการทำงาน (Flowchart)
1. **Input**: รับข้อมูล Features ของดอกไม้จำนวน 4 ตัวแปร
2. **Preprocessing**: นำข้อมูลมาผ่าน `StandardScaler` เพื่อปรับลดความเหลื่อมล้ำของตัวเลข (จำเป็นมากสำหรับ SVM)
3. **Modeling**: นำข้อมูลส่งเข้าโมเดล SVM โดยใช้ **Linear Kernel** (เนื่องจากข้อมูลชุดนี้สามารถใช้เส้นตรงแบ่งกลุ่มได้ชัดเจน)
4. **Evaluation**: ประเมินผลและแสดงกราฟ Confusion Matrix

##  ผลลัพธ์ (Results)
* **ความแม่นยำ (Accuracy):** 100%
* **จุดเด่น:** ระบบกินทรัพยากรน้อย ทำงานได้ไว และมีความน่าเชื่อถือสูง เพราะเราสามารถอธิบายการขีดเส้นแบ่งข้อมูลของ SVM ได้ชัดเจนครับ
