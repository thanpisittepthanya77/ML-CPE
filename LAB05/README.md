## วัตถุประสงค์
* เพื่อเข้าใจหลักการทำงานของ Support Vector Machine (SVM) และแนวทางการประยุกต์ใช้ในงานจริงทั้งด้านการจำแนกและการพยากรณ์[cite: 1]
* เพื่อพัฒนาผังการทำงาน ประมวลผล และแสดงผลลัพธ์ เพื่อพัฒนาระบบต้นแบบร่วมกับ SVM ในการจำแนกและการพยากรณ์ได้อย่างถูกต้อง[cite: 1]

## รายละเอียดโปรเจกต์
โปรเจกต์นี้เป็นการนำโมเดล SVM มาใช้จำแนกชุดข้อมูล (Classification) โดยเปรียบเทียบประสิทธิภาพของเคอร์เนล 3 รูปแบบ ได้แก่ Linear, Polynomial, และ RBF[cite: 1] 

กระบวนการทำงานประกอบด้วย:
1. การโหลดและจัดการชุดข้อมูลเบื้องต้น
2. การปรับสเกลข้อมูล (Standardize input features) ก่อนนำไปเทรนโมเดล[cite: 1]
3. การเทรนโมเดลด้วยเคอร์เนลที่แตกต่างกันทั้ง 3 รูปแบบ[cite: 1]
4. การประเมินผลแต่ละโมเดลด้วยค่าความแม่นยำ (Accuracy)[cite: 1]
